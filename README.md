# Scout System · Photo Edit Toolkit

整合圖像工具的統一工作台，由 **Scout System** 開發維護。

## 工具一覽

| 工具 | 路徑 | 說明 |
|------|------|------|
| **DPI 列印** ⭐ | `/dpi` | AI 圖 → DPI / 實際 cm、品質診斷、pHYs PNG、批次 |
| **馬賽克** | `/mosaic` | 框選臉部打碼（馬賽克／模糊／黑塊），保護小朋友私隱 |
| **去背換底** | `/background` | 去背、靈敏度／柔邊、純色／漸層／背景圖 |
| **裁切縮放** | `/resize` | 比例裁切、旋轉翻轉 |
| **浮水印** | `/watermark` | **自訂文字**版權浮水印（不強制品牌字） |
| **邊框出血** | `/bleed` | 出血線、安全區、裁切標記、裝飾邊框 |
| **拼圖九宮格** | `/collage` | 2×2／3×3 等多圖拼版 |
| **浮雕 3D** 🆕 | `/relief` | 相片／Logo → 灰階高度圖 → 3D 浮雕，匯出 STL / OBJ / 高度圖 PNG |
| **SVG 向量** | `/svg` | PNG → SVG |
| **QR / 條碼** | `/qrcode` | 自訂 QR 與條碼 |

## 建議工作流

**活動相上網：** 馬賽克 → 裁切／拼圖 → 自訂浮水印  

**AI 圖印刷：** 去背／裁切 → 邊框出血 → DPI 300 匯出  

**3D 列印紀念品：** 去背／裁切 → 浮雕 3D（調對比、深度）→ 匯出 STL 入切片軟件  

## 浮雕 3D 說明

- 影像先轉灰階高度圖（亮＝高、暗＝低），再生成密封（watertight）網格：頂面浮雕 + 底板 + 側牆。
- 內建預設：照片浮雕、線稿／Logo、印章凹雕、襟章名牌。
- 可調幾何（深度、底板厚度、輸出寬度 mm、網格解析度、邊緣緩降）與影像（亮度、對比、Gamma、平滑、銳化、自動高度拉伸）。
- 「凹凸反轉 + 水平鏡像」＝印章／模具模式。
- 匯出：二進位 STL、OBJ、高度圖 PNG。全部在瀏覽器本機運算，圖片不會上傳。
- 3D 引擎（three.js）以動態載入方式打包，不影響其他工具的首屏速度。
